# Wizard
Multi-step flow for setup tasks: connect an account, add a mail domain, onboard a project, migrate mailboxes.

`hq-steps` across the top (numbered, done steps muted with a check, current step `accent`), one focused form per step, footer with Zurück / Weiter (primary) and the step count. Steps are few (3–5) and each can be revisited. Never use a wizard for something that fits one form.
