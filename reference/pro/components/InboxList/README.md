# InboxList
Message list for one mailbox or the unified inbox, with agent activity visible per mail.

Row: unread dot, sender (bold when unread), time (mono), subject + snippet (`fg-300`), then tags: recipient address in unified view, agent state ("Entwurf bereit · Support-Agent" as signal badge, "Beantwortet · Agent"), attachment/receipt detection. Selected row `bg-300`. J/K to move, E archive, R reply.
