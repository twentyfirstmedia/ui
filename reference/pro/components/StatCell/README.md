# StatCell
A KPI inside a HairlineGrid cell: eyebrow, `numeric` value, delta and an optional sparkline.

Use 3–5 in one row at the top of an overview, only when those numbers are the point of the screen. The delta names its comparison ("vs. Sept."). Up/down is shown with an arrow glyph and sign; color it `ok`/`danger` only when "up" is clearly good or bad (revenue vs. costs).
