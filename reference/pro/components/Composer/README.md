# Composer
Write or reply; the sender is any address the admin can use, chosen per message.

Fields as rows on hairlines: Von (address select, defaults to the active mailbox), An, Cc/Bcc on demand, Betreff, body. Toolbar: attach (also drag files onto the body or paste), dictate, signature, "Mit Agent verfassen" (asks the mailbox's agent for a draft). Send is primary (⌘↵). Agent drafts open here with a "Entwurf von Support-Agent" note.
