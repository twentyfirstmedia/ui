# Dialog
Modal for a focused decision or a short form; header, body, footer separated by hairlines.

Max 480px (forms up to 640px). Title in `heading`. Footer on `bg-000` with actions right: secondary first, primary last. Destructive confirmations name the object and the consequence ("Postfach sales@jasondevine.de und 1.204 Mails löschen?") and use a `--danger` primary. Esc closes unless there are unsaved changes.
