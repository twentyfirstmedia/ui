# FileDropzone
Drop or pick files: receipts, invoices, brand assets, CSV imports.

Dashed `line-300` frame on `bg-000`; while dragging over, solid `focus` border and `bg-200` (`.is-over`). Says which file types and size are accepted. Below it, one `hq-filerow` per file with name, size, a Progress bar while uploading, then a status shape. Detected receipts get "Beleg erkannt".
