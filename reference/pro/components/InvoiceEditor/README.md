# InvoiceEditor
Create an outgoing invoice: company, customer, line items, VAT, terms; the InvoicePreview updates live beside it.

Line items as an editable table (Leistung, Menge, Einheit, Preis, USt, Summe) with add/remove rows; totals computed below in mono. The number comes from the company's sequence on issue, not before ("wird bei Ausstellung vergeben"). Actions: Als Entwurf speichern, Ausstellen & senden (primary, approval when created by an agent). E-invoice format chosen per customer (PDF, ZUGFeRD, XRechnung).
