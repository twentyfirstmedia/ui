# BudgetStop
What a project looks like when its monthly budget hit 100 %: agents paused, state kept, one way out.

Replaces the project overview header with a `danger` banner and a summary cell: what is paused, what is still running (nothing), spend vs. budget, the date the budget resets. Actions: "Budget erhöhen" (primary), "Einzelnen Agent freigeben". Paused agents show the warn triangle "Pausiert · Budget" everywhere, including the city.
