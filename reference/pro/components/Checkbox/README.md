# Checkbox
Checkbox and radio for multi- and single-choice; 14px, `line-300` border, `accent` fill when checked.

Use `.hq-check` for multi-select (table rows, filters) with an `indeterminate` state for "some selected", `.hq-radio` (round, the only round control) for exclusive choices. Wrap with `label.hq-checkrow` so the label is clickable.
