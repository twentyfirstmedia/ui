# DnsRecordTable
DNS records of one domain from Cloudflare: type, name, content, TTL, proxy status, row actions.

Type as `--mono` Badge, name and content in mono (content truncates with full value in a tooltip/Sheet). Proxy shown as Cloudflare icon (on) or muted (DNS only). Edits by agents need approval; edits by admins confirm destructive changes (MX, NS) in a Dialog.
