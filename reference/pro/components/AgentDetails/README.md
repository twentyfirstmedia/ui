# AgentDetails
The right column of the ChatWorkspace: everything about the agent you are talking to, without leaving the chat.

Sections: identity (avatar, role, project, room, status), numbers (model, cost today and this month, runs), triggers (Auslöser), tools, memory entries, last runs with links to the Langfuse trace. Each section links to the full editor (model override, triggers, memory) in the agent's settings. For agent-to-agent threads it lists the participants and the route (via Main Brain); for the Main Brain it shows global numbers.
