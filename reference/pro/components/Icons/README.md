# Icons
Lucide for every UI icon; Simple Icons for brand and social logos, which Lucide no longer ships.

- **Lucide** (`lucide-react` in the app, pinned version): 16px (`icon-md`) in UI, 14px (`icon-sm`) in badges and dense cells, stroke-width 1.5, `currentColor`. Icons inherit text color; never color an icon by itself except a status icon.
- **Simple Icons** (`simple-icons` / `@icons-pack/react-simple-icons`): brand marks for channels and providers (Instagram, WhatsApp, Stripe, Cloudflare, Hetzner …), monochrome in `currentColor` at the same sizes. Never recolor to brand colors in UI; brand color appears only in a project's CI.
- Approvals use Lucide `diamond`, matching the signal shape.
- No emoji in the UI.
