# ApprovalInbox
The list of all open approvals across projects, oldest first, next to the selected ApprovalCard.

Rows: diamond, action sentence, agent · project, risk family badge, age (mono, `warn` when close to escalation). Filters: Projekt, Familie, Agent. Keyboard: J/K to move, A–D to decide on the selected card. Decided items move to "Erledigt" with decider and time.
