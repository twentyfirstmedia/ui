# PushNotification
How an approval arrives on the phone: title, agent and project, the action in one line, and quick actions.

Web Push now, APNs in the iOS app later, same content. Actions on the notification: "A · Ausführen" and "Öffnen" (B–D need the app because they take text). Money and infrastructure approvals only offer "Öffnen" so the full payload is seen before deciding. Grouped per project when several arrive.
