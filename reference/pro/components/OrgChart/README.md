# OrgChart
The hierarchy as a chart: Main Brain → Head Agents per project/team → executing agents, plus the shared infra agents.

Nodes are hairline boxes with avatar, name, role and a status shape; the Main Brain node has an `fg-100` border. Connectors are 1px `line-300` lines. Click a node to open the agent; projects collapse to one node when zoomed out. This view reads from the project config, so it is always the real structure, never a drawing.
