# BulkActionBar
Appears when rows are selected: count, the actions that apply to all of them, and clear selection.

Inverted bar (`accent` fill) replacing the table header area so it can't be missed. Actions are verbs ("Buchen", "Projekt zuweisen", "Archivieren"); destructive ones confirm with the count ("12 Mails löschen?"). Esc clears the selection.
