# NotificationCenter
Panel behind the bell: everything that happened while you were away, grouped by day, filterable.

Opens as a 380px `hq-layer` under the top-bar bell. Items: status shape, bold title (normal weight once read), one-line detail, time. Approvals link into the ApprovalInbox and are never only here. Header: "Alle gelesen", filter Alle / Freigaben / Fehler. Push notifications and this panel show the same items.
