# ConfigPRSummary
Plain-language summary of a structure change the Main Brain proposes as a pull request: new project, team, agents, tools.

Written so it can be judged without reading code, on a phone. Lists what gets created, which tools each agent gets, and highlights any tool from the Infrastruktur, Eigene Apps or Geld families with a lock badge. Actions: "PR auf GitHub öffnen", "Ablehnen". Merge happens on GitHub; HQ never auto-merges.
