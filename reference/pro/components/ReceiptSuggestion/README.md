# ReceiptSuggestion
An invoice found in a mail attachment, read out and proposed as a booking; confirm with one click.

Shows the source (mail, sender, attachment), extracted fields with confidence (Lieferant, Datum, Brutto, USt), and editable suggestions for Firma, Projekt, Kategorie. Actions: "Übernehmen & buchen" (primary), "Bearbeiten", "Kein Beleg". Low-confidence fields are marked with the warn triangle and focused first.
