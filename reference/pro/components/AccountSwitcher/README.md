# AccountSwitcher
Top-left mailbox switcher: one login, every address across ~25 domains, switch without signing in again.

Trigger shows the current address in mono and its domain. The menu has a search field (focus on open, type "sales" to filter), "Alle Postfächer" (unified inbox) first, then addresses grouped by domain with unread counts. Keyboard: ⌘1–9 for pinned addresses, ⌘⇧A opens the switcher. The chosen address also becomes the default sender in the Composer.
