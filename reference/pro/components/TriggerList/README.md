# TriggerList
Schedules, events and webhooks that start agents, with who created them and when they run next.

Columns: type icon (clock, zap, webhook), rule in plain German ("Mo 09:00 · wöchentlich", "Neue Mail an support@"), target agent, created by (Config, Main Brain, the agent itself), next run (mono), on/off Switch. Self-created triggers show the agent's avatar so humans can spot agents scheduling themselves.
