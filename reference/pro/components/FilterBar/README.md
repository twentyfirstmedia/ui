# FilterBar
Active filters above any list or table, as removable chips, plus "Filter hinzufügen".

Chips read "Feld: Wert" (`hq-chip` with `.k` key in `fg-300`). Saved views on the right. The bar is part of the list's frame (`bg-100`, hairline below). Clearing all filters is one action. Filters are mirrored in the URL so views can be shared.
