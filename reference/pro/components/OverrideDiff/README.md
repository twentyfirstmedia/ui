# OverrideDiff
Shows how an agent's runtime override differs from its code default, with discard and "move to code" actions.

Header: field (Instruktion, Modell), versions ("Code-Default v1 → Override v3"), who changed it (Main Brain after feedback, a human). Body: line diff, additions on `ok-bg` with `+`, removals on `danger-bg` struck through with `−`. Actions: "Override verwerfen", "Als PR in den Code übernehmen" (opens a config PR via the Main Brain).
