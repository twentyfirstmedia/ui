# CodeViewer
Read-only JSON, YAML or code: tool inputs/outputs, webhook payloads, config files, MCP schemas.

`pre.hq-code` on `bg-000`, mono 12/20, minimal highlighting (keys `fg-100`, strings `ok`, numbers `info`, booleans `warn`, comments `fg-400`). Header with language badge, Copy button and a line count. Long payloads collapse after 30 lines with "Alles anzeigen". Secrets in payloads are masked before display.
