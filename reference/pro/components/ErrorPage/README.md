# ErrorPage
Full-page states when a route can't render: 404, 403 (no access), 500, and maintenance.

Left-aligned on the grid background: status code in large mono `fg-300`, a heading that says what happened, one sentence on what to do, one or two actions (Zur Übersicht, Erneut versuchen). Include the request ID in mono for 500s so it can be found in logs. No illustrations.
