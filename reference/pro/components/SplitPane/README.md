# SplitPane
Resizable panes for list-detail views: Webmail, Freigaben, Finanzen with a Sheet docked.

The divider is the 1px hairline itself with a 5px invisible grab area; on hover and drag it turns `focus`. Double-click resets. Pane sizes persist per user and view. Minimum widths keep both panes usable; below 768px panes stack and the detail opens full screen.
