# MobileTabBar
Bottom navigation on phones (PWA now, iOS app later): Stadt, Freigaben, Mail, Finanzen, Mehr.

Five equal cells divided by hairlines, 56px plus the safe-area inset. Active item `fg-100` with a 1px `accent` line on top. Freigaben carries the signal count. "Mehr" opens a sheet with the remaining modules from the registry. Approvals are reachable in one tap from anywhere.
