# MoneyInput
Amount entry in euro: mono, tabular, right-aligned, German format (1.234,56), with VAT rate beside it.

`.hq-inputgroup` with the amount `.hq-input--mono` right-aligned and a `€` affix; a VAT Select (19 %, 7 %, 0 %, Reverse Charge) next to it, and the computed net/VAT shown as caption below. Parse both "1234.5" and "1.234,50"; always display German format.
