# SegmentedControl
Switches between 2–5 views or modes of the same content: Dichte, Zeitraum, Stadt/Liste.

Pressed segment: `bg-300` and `fg-100` (`aria-pressed="true"`). Segments are divided by `line-200` hairlines inside a `line-300` frame. The density switch (Kompakt / Komfortabel) is the reference use.
