# Avatar
Square monogram that identifies an agent, a human or the Main Brain.

- Agents: two-letter monogram in `mono` on `bg-300` (`SA` Support-Agent, `HS` Head Sales).
- Humans: `--human`, `bg-100` with a `line-300` border.
- Main Brain: `--brain`, `accent` fill. Only the Main Brain uses it.
- Optional status shape bottom-right (StatusIndicator).
Square on purpose: avatars match the voxel city and the sharp system. 24px default, `--lg` 32px.
