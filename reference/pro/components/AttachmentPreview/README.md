# AttachmentPreview
Opens an attachment without downloading: PDFs and images in a Sheet, with what HQ recognized.

Left: the document on `paper` (pages scroll). Right: file facts and recognition results (invoice fields, sender match), plus actions: Herunterladen, Als Beleg verbuchen, An Agent übergeben. Unknown or risky types (executables, macros) are never previewed and show a warning instead.
