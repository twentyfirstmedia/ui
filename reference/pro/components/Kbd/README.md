# Kbd
Shows a keyboard shortcut; HQ is keyboard-first, so every frequent action advertises its key.

Use inside buttons, menu items, tooltips and the command palette. Mac glyphs (⌘ ⌥ ⇧) on macOS, `Ctrl` elsewhere. Approval options use single letters A–D.

**Consumer provides:** the key text. Set in `mono-sm` style at 11px, `fg-300` on `bg-200`, `line-200` border.
