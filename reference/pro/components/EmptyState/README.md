# EmptyState
What an empty area shows: what will appear here and the one action that fills it.

Left-aligned (never centered illustrations), on the faint `.hq-gridbg`. An eyebrow, one sentence in `fg-200`, one button. No mascots, no emoji. Example copy: "Keine offenen Freigaben. Agents fragen hier, bevor sie Geld, Infrastruktur oder eure Apps anfassen."
