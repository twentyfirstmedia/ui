# MessageView
Reading pane for one mail: subject, sender/recipient, attachments, body, and the agent panel for drafts.

Subject in `heading`, header fields as KeyValue (Von, An, Konto). Attachments as `.hq-attach` chips; detected invoices get a "Als Beleg erkannt" link into Finanzen. If an agent drafted a reply, a panel above the body shows the draft with Freigeben / Bearbeiten / Verwerfen. Actions bar: Antworten, Weiterleiten, An Agent übergeben (Menu with agents of the mailbox's project).
