Half-ring showing one value against a maximum: a goal, a budget, a quota.

Props: `value`, `max`, `caption`, `format(v)`, `tint`, or `thresholds` ([warn, danger] switches mint → butter → blush), `size`, `stroke`, `showRange`, `label`.

- One gauge per idea; never put gauges in a row to compare things — use a BarChart.
- Use `thresholds` for limits (budgets, storage), a fixed `tint` for goals where more is better.
