Grid of cells shaded by value, for patterns across two dimensions (weekday × hour, week × day).

Props: `rows`, `cols` (labels), `values` (rows × cols numbers), `colEvery` (label every nth column), `caption`, `format(v)`, `label`.

- Five steps of one hue (mint-ink mixed into the surface), so it reads by lightness in both themes and for color-blind viewers.
- The footer shows the hovered cell's exact value; keep the Less–More scale visible.
