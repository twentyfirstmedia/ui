# Reference (read-only)

The specification for the kits. Do not edit; port from it.

- `halo/source/`: the Halo bundle (`halo.js`, `halo.css`, `tokens.css`) as built in the Halo UI design system on claude.ai.
- `halo/design-system/`: docs, tokens, props (`components/index.d.ts`), labels and one preview per component group.
- `halo/demo/`: demo app showing the components in real screens (`halo-workspace.html` opens offline-capable in a browser; it loads React from a CDN).
- `pro/`: the Pro look (tokens, rules, component and screen previews). Take the look only, not the copy or app-specific content.
