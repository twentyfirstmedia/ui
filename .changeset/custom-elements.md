New package `@twentyfirstmedia/elements`: every component as a custom element (`<tf-button>`, `<tf-data-table>`, `<tf-provider>` …) for plain HTML, Vue, Svelte, Angular, Astro and server templates. Attributes and properties map to props, callbacks become DOM events with the argument in `detail`, and children and `slot="…"` fill content props. Ships ESM and a classic-script bundle with React included, TypeScript types and a Custom Elements Manifest. New guide: Plain HTML and frameworks.
