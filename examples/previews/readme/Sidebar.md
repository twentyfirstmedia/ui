# Sidebar

App navigation down the side: groups with headings, counts, one level of nested pages and a
collapsed mode with icons only.

- The collapse button sits in the footer next to anything you pass (an account, settings).
- Collapsed, labels stay available as tooltips and to assistive tech.
- On phones the sidebar takes the full width; place it in a `Drawer` (`side="left"`) for an
  off-canvas menu.
