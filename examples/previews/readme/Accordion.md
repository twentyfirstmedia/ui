# Accordion

Stacked sections that open and close. One section at a time by default, or several with `multiple`.

- `cards` (default) shows each section as a card; `flush` uses hairlines, for use inside a panel.
- Keyboard: Tab reaches each header, ↑/↓ move between headers, Home/End jump, Enter or Space toggles.
- Headers are buttons with `aria-expanded`; panels are regions labelled by their header.
