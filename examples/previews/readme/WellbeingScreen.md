# WellbeingScreen

A wellbeing dashboard in glass: sleep, streak and steps as tinted glass tiles, last nights' sleep, today's goal, mindful minutes, mood and habits, and a journal prompt, over the kit's ambient colours.

- The whole app shell is glass: top bar, rail, panels, tiles and dock float over `Ambient`.
- Built from `UIProvider surface="glass"`, `Ambient`, `AppShell`, `StatTile`, `BarChart`, `ProgressRing`, `AreaChart`, `Segmented` and `Checkbox`.
