# Menubar

A desktop-style row of menus (File, Edit, View). Each menu is a regular `Menu`, so items can have
icons, shortcuts, checkbox and radio states and submenus.

- Keyboard: ←/→ move between menus (and switch the open one), ↓/Enter/Space open, ↑/↓ move inside,
  → and ← open and close submenus, Escape closes and returns to the bar.
- Moving the pointer across the bar switches menus once one is open.
