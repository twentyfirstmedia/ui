# VitalTile

One health value with its healthy range: the value, a band with the normal zone and a marker, a
status in words (in range, below, above) and an optional trend.

- `normal` is the healthy range; `scale` the whole band (default: the range with room around it).
- `digits` for decimals, `unit`, `caption` for the source and time of the reading.
- The status is text in a badge, never colour alone.
