# MatchList

Who fits: buyers or tenants for a property, or properties for a buyer. Best first, with the match
in percent, a bar and which criteria are met.

- Missed criteria stay visible but muted, and are read out as "not met".
- `onContact(id)` adds the action per match; `contactLabel` names it ("Send exposé").
- In a narrow box the score moves under the name.
